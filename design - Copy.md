# GadgetCartels.in — Visual Design System

## 1. Design Direction

**Style:** Premium street-tech ecommerce / editorial electronics.

Keywords:

- bold
- loud
- energetic
- premium
- futuristic
- high contrast
- playful
- experimental
- commercial

The visual identity is built around a nearly black canvas and extremely bright accent colors.

## 2. Color System

### Core

- Background: `#050505`
- Primary surface: `#0B0B0B`
- Secondary surface: `#111111`
- White: `#F5F5F5`
- Muted text: `#A3A3A3`
- Border: `#252525`

### Accent

- Neon Yellow: `#DFFF00`
- Electric Purple: `#6D28FF`
- Bright Cyan: `#20D9E8`
- Hot Pink: `#FF2FA8`
- Orange: `#FF7A00`

Use accents as large visual blocks, not tiny decorative highlights only.

## 3. Typography

The reference uses an extremely bold condensed display style.

Preferred stack:

### Display

Use a condensed heavy font if available, for example:

- Anton
- Bebas Neue
- Oswald Heavy
- Impact fallback

### Body

Use a clean sans-serif:

- Inter
- Poppins
- Arial fallback

### Rules

Display headlines:

- uppercase
- very heavy
- tight line-height
- tight letter spacing
- often split across multiple lines

Body text:

- compact
- highly readable
- smaller than conventional ecommerce websites

## 4. Typography Scale

Approximate desktop hierarchy:

- Hero display: `clamp(4rem, 8vw, 8.5rem)`
- Section display: `clamp(3rem, 6vw, 6rem)`
- Card heading: `1.5rem–2.25rem`
- Body: `0.85rem–1rem`
- Eyebrow: `0.65rem–0.8rem`
- Labels: `0.6rem–0.75rem`

The exact size should be tuned against the reference image rather than blindly following these values.

## 5. Spacing

Use a structured spacing system:

- 4px
- 8px
- 12px
- 16px
- 24px
- 32px
- 48px
- 64px
- 80px
- 96px
- 120px

Large sections should have strong vertical rhythm but not excessive empty space.

## 6. Containers

Desktop content width:

- approximately `92–95vw`
- max width around `1500–1650px`

The reference uses broad compositions rather than narrow centered content.

## 7. Borders

Use subtle borders:

- `1px solid #252525`

Accent borders may use neon yellow or purple sparingly.

## 8. Corners

Use a mixed geometry system.

Do not make every component equally rounded.

Recommended:

- large panels: 18–24px
- product cards: 16–22px
- buttons: 0–8px depending on component
- circular controls: 9999px
- some editorial cards may use clipped or asymmetric corners

## 9. Buttons

Primary:

- neon yellow background
- black text
- bold uppercase
- compact
- arrow/icon
- strong contrast

Secondary:

- transparent/dark
- white text
- subtle border
- compact arrow icon

Buttons should feel like physical UI labels rather than generic SaaS buttons.

## 10. Imagery

Product imagery is a major part of the visual system.

Use:

- large cutout products
- realistic product photos
- strong cropping
- overlap
- layered positioning
- dark surroundings
- bright geometric backplates

Do not place products in generic centered cards unless the reference does.

## 11. Decorative Language

Use restrained technical details:

- tiny grid dots
- circuit-like lines
- corner marks
- diagonal stripes
- small crosses
- arrows
- thin technical lines
- oversized faint background typography

Decorations should support composition rather than compete with products.

## 12. Shadows / Glow

Use very limited shadows.

Preferred effects:

- subtle black shadow behind products
- low-intensity neon glow around selected accents
- no large blurry glassmorphism shadows

## 13. Layout Personality

The layout should be asymmetric.

Avoid:

- perfectly uniform grids everywhere
- identical card dimensions in every section
- centered hero content
- excessive empty margins

Prefer:

- overlapping products
- offset cards
- editorial blocks
- varying card heights
- controlled visual tension

## 14. Motion

Motion should feel quick and physical:

- 150–250ms hover transitions
- subtle card lift
- product image scale around 1.02–1.05
- arrow movement
- badge rotation only where useful
- gentle marquee effects if needed

Never let animation distract from shopping.

## 15. Mobile Design

Mobile must preserve:

- black background
- condensed display typography
- neon accents
- product prominence
- strong CTA hierarchy

Mobile adaptations should be intentional rather than simply reducing desktop dimensions.
