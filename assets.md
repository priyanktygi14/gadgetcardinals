### Hero

- main iPhone/product cutout
- AirPods cutout
- Apple Watch cutout

- decorative technical graphics

### Categories

- iPhone image
- MacBook image

### Deals

- AirPods deal image
- iPhone deal image
- Apple Watch deal image

### Decorative

- diagonal stripe SVG
- arrow icons
- circuit-line graphics
- dot grid
- quote mark
- small technical symbols

## Asset Rules

Prefer WebP/AVIF for large raster assets where supported.

Use SVG for:

- logos
- icons
- simple decorative shapes

Do not upscale low-resolution images.

Keep transparent product cutouts where possible.

## Suggested Folder Structure

```text
public/
  assets/
    brand/
    hero/
    products/
    categories/
    deals/
    icons/
    decorative/
    social/
```

## Naming

Use predictable names:

```text
iphone-hero.webp
airpods-hero.webp
watch-hero.webp

deal-iphone.webp
logo-white.svg
icon-search.svg
```

## Important

The reference image is a composition reference.

Do not use the screenshot itself as the final website background or as a single giant image.

Recreate the UI using HTML/CSS/components and actual assets.
